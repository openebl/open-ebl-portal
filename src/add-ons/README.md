# Add-ons

The `add-ons` folder in the `bluex-ebl-portal` repository contains external components or services that can enhance the capabilities of the EBL (Electronic Bill of Lading) portal.

## Purpose

The purpose of the `add-ons` folder is to provide a centralized location for integrating external services into the EBL portal. These add-ons can extend the functionality of the portal by providing additional features or services that are not natively available.

## Included Add-ons

Currently, the `add-ons` folder includes the following external service:

### Doc-Extraction

The `doc-extraction` add-on is a service that allows the EBL portal to read uploaded bill-of-lading documents and extract specific columns from them. This feature can be useful for automating data extraction and improving the efficiency of document processing within the portal.

To use the `doc-extraction` add-on, refer to the documentation provided in the respective subfolder within the `add-ons` directory.

## Contributing Add-ons

If you have developed an add-on that can enhance the capabilities of the EBL portal, you can contribute it to the `add-ons` folder. Please follow the contribution guidelines provided in the repository's documentation.
