## UI Components

This folder contains UI components generated by the [shadcn/ui](https://ui.shadcn.com/) library. These components are reusable building blocks that can be used to create user interfaces for the Bluex EBL Portal project.

By storing the components in this folder, it provides a centralized location for managing and organizing the UI components. This promotes code reusability, consistency, and maintainability throughout the project.

Feel free to explore the different components available in this folder and utilize them in your application development.
